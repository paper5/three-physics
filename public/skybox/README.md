# Skybox

Place 6 square skybox images here to replace the procedural gradient sky.

## Required files

| File    | Face         |
|---------|--------------|
| px.jpg  | +X (right)   |
| nx.jpg  | -X (left)    |
| py.jpg  | +Y (up)      |
| ny.jpg  | -Y (down)    |
| pz.jpg  | +Z (front)   |
| nz.jpg  | -Z (back)    |

All images should be the same resolution (e.g. 1024×1024) and preferably in `.jpg` format.

## Free skybox sources

- [Poly Haven](https://polyhaven.com/skyboxes) – CC0 licensed
- [OpenGameArt](https://opengameart.org/art-search?keys=skybox)
- Create your own with [Panorama to Cube](https://jaxry.github.io/panorama-to-cube/)

Once the files are in place, restart the dev server and the skybox loads automatically.
